# charter
This is a PHP application for building DFDs, flowcharts, and ERDs.
It has been helpful in teaching technology in secondary schools and the style matches the QCAA (Queensland Curriculum and Assessment Authority) syllabus for Year 12 Digital Solutions.

# installation
You will need to map a MariaDb/MySQL database in the charter-config.rename.php file and rename this to charter-config.php
